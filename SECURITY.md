# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Report them privately through [GitHub private vulnerability reporting](https://github.com/jusso-dev/blueboard/security/advisories/new), with steps to reproduce and the impact you see. You'll get an acknowledgement within five working days.

## Supported versions

Only the latest commit on `main` gets fixes.

## Security guide

How blueboard protects its containment capability (threat model, controls, the Microsoft permissions it holds, the action policy, a hardening checklist, monitoring and a runbook) is in **[docs/SECURITY.md](docs/SECURITY.md)**. Read it before turning on `BROKER_EXECUTE`.
